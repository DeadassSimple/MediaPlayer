# Deadass Simple Media Player

It plays local media files.
Music, movies, podcasts, shows, whatever.

No bullshit, just a good & simple app that plays media files.


## Dogfooded as fuck

I (Ky) needed a local media player so I made this. It's the only way I listen to my music, and watch most of my local video files!



## LLM Usage

[I, Ky,](https://KyLeggiero.me) reviewed all the code in this repo, and wrote the vast majority of it. Nothing gets into production code without my careful review and explicit approval, no matter who or what wrote it. See [the PRs](https://github.com/BlueHuskyStudios/DeadassSimpleMediaPlayer/pulls) for proof of that.

Some of it was written using LLMs, either directly writing it, or assisting contributors like myself.

Because transparency fucking matters, I'm making sure all of that is documented in the [LLM transparency](./LLM%20transparency) folder of this repo.
